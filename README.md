# ESP32 F1 Timer — настольное табло Формулы-1

Небольшое табло на ESP32 и 2-дюймовом цветном дисплее. Оно само следит за календарём Формулы-1: показывает обратный отсчёт до ближайшей сессии, расписание уик-энда, схему трассы и таблицу чемпионата.

Все данные загружаются из открытых источников, поэтому после прошивки ничего не нужно вписывать в код или обновлять руками. Wi-Fi настраивается с телефона.

Ещё табло умеет:

- само определять текущий этап и переключаться на следующий после гонки;
- поддерживать любой сезон: календарь, трассы и команды берутся из интернета;
- определять часовой пояс по IP-адресу;
- обновлять данные каждые 30 минут, а в гоночный уик-энд каждые 5 минут;
- ставить схемы трасс для всех этапов календаря, загружая их по мере необходимости.

## Схема подключения

<img width="4800" height="3200" alt="image" src="https://github.com/user-attachments/assets/d1575a3b-bf64-439f-ad78-f99996f29948" />


| Дисплей / кнопка | ESP32 |
|---|---|
| GND | GND |
| VDD | 3V3 |
| SCL | GPIO 18 |
| SDA | GPIO 23 |
| RES | GPIO 17 |
| DC | GPIO 16 |
| CS | GPIO 5 |
| BL | 3V3 |
| Кнопка, вывод 1 | GPIO 21 |
| Кнопка, вывод 3 (по диагонали) | GND |

> Выводы SCL и SDA на этом дисплее — это шина **SPI** (SCK и MOSI), а не I²C.
> Резистор к кнопке не нужен: используется встроенная подтяжка `INPUT_PULLUP`.

## Установка

1. Установите **Arduino IDE 2.x** с [arduino.cc](https://www.arduino.cc/en/software).
2. **Tools → Board → Boards Manager**: установите **esp32 by Espressif Systems** (версия 3.x).
   Если пакета нет в списке, добавьте в *File → Preferences → Additional boards manager URLs*:
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. **Tools → Manage Libraries**: установите библиотеки (на вопрос о зависимостях ответьте *Install All*):
   - **Adafruit ST7735 and ST7789 Library**
   - **Adafruit GFX Library**
   - **ArduinoJson** (Benoit Blanchon, версия 7.x)
   - **WiFiManager** (tzapu)
4. Откройте `F1_Live/F1_Live.ino`.
5. Настройки в меню **Tools**:
   - Board: **ESP32 Dev Module**
   - Port: порт вашей платы
   - Upload Speed: 921600 (при ошибках загрузки — 115200)
   - Partition Scheme: Default 4MB (если скетч не помещается — *Huge APP (3MB No OTA)*)
6. Нажмите **Upload**.

Если плата не определяется на Windows, установите драйвер USB-чипа вашей платы (CH340 или CP210x) или попробуйте другой кабель: часть кабелей умеет только заряжать.

## Первый запуск

1. На экране появится инструкция **WiFi setup**.
2. Подключитесь с телефона к Wi-Fi сети **F1-Timer**. Страница настройки откроется сама (или откройте `192.168.4.1`).
3. Выберите домашнюю сеть, введите пароль и нажмите *Save*.

Табло запомнит сеть и дальше будет подключаться само.

> ESP32 работает только с Wi-Fi **2,4 ГГц**. Если табло не видит сеть, проверьте, что роутер раздаёт 2,4 ГГц. Если раздаёте интернет с iPhone, включите «Максимальную совместимость» в настройках режима модема.

## Управление

| Действие | Результат |
|---|---|
| Одно нажатие | следующий этап / страница таблицы |
| Двойное нажатие | следующий экран |
| Удержание (больше 0,6 с) | обновить данные сейчас |
| Удержание **BOOT** больше 5 с | забыть Wi-Fi и перезапустить настройку |

API ключи не нужны. Пожалуйста, не уменьшайте интервалы обновления сильно: это бесплатные сервисы с ограничением числа запросов.

## Если что-то не так

Откройте **Serial Monitor** на скорости **115200**. Там видно подключение к Wi-Fi, каждую загрузку данных и причину последнего перезапуска.

- **Экран белый.** Данные не доходят до дисплея: проверьте провода SCL/SDA/CS/DC/RES и пайку.
- **Экран мерцает, плата перезагружается** (`brownout` в логе). Не хватает питания: возьмите короткий кабель и зарядку от 1 А, можно поставить конденсатор 470–1000 мкФ между 3V3 и GND.
- **Картинка не появляется, хотя данные идут.** В `setup()` замените `SPI_MODE3` на `SPI_MODE0`.
